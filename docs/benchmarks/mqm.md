# MT Metric Reliability (MQM)

## About

The MQM benchmark translates FLORES+ English sentences into each configured
target language with the model under test, scores the translations with BLEU,
chrF and COMET, and reports, next to each score, what is known about how well
that metric tracks human judgment **for that target language**.

**Why this matters:** a metric score is only as useful as the metric's agreement
with human judgment, and that agreement varies by language. It also varies with
*which* human labels it is measured against: AmanaMT v2 found that several
apparent language and translation-direction effects trace to the annotation
protocol instead. This benchmark therefore reports per-language evidence and
says how direct that evidence is, instead of one reliability number per metric.

**What it does:**

1. Loads the model under test (`settings.model.model_checkpoint_path`) as a
   seq2seq translation pipeline.
2. Translates FLORES+ English source sentences into each configured target language.
3. Computes BLEU, chrF and COMET against the FLORES+ references. BLEU uses the
   FLORES-200 SentencePiece tokenizer (spBLEU) for scripts written without
   spaces between words (zh, ja, th, lo, my, km); the default tokenizer gives
   near-zero BLEU there.
4. Reports per-language corpus-level metric scores.
5. Attaches per-language reliability evidence from AmanaMT v2 (Thompson and
   Ringger; revision of ACL Anthology `2026.wmt-main.42`): segment-level
   Spearman correlation with human labels, its bootstrap confidence interval,
   pairwise accuracy, the label type and the language pairs it was measured on.

### Evidence levels

The benchmark translates **English into X**, so the most relevant evidence is a
measurement on en->X translations against human labels. Each language gets one level:

| Level | Meaning | Languages |
|---|---|---|
| `direct_en_to_x` | Human labels on en->X translations (expert MQM or DA) | de, ru, es (MQM); cs, tr, ha (DA) |
| `indirect` | Human labels only for X->en | zh, he (MQM); km, ps (DA) |
| `none` | Synthetic (LLM) labels, or labels AmanaMT v2 found uninformative | sw, ht, lo (synthetic); uk |

For `none` languages, treat every metric score as unvalidated. The values are
descriptive: they come from WMT test sets of particular years and domains, and
stronger metrics than these three exist (MetricX-24 had the highest mean
correlation in AmanaMT v2).

The numbers are in `src/mirroreval/benchmarks/mqm/amanamt_v2_reliability.json`,
generated by `scripts/export_mirror_eval_reliability.py` in
[amana-mt](https://github.com/byu-matrix-lab/amana-mt) from its result files.
Do not edit the JSON by hand; regenerate it there and copy it over.

## Requirements

### Model interface

The model under test must satisfy two requirements:

1. **Loadable as a HuggingFace translation pipeline** — the benchmark calls:
   ```python
   pipeline("translation", model=model_checkpoint_path,
            src_lang="eng_Latn", tgt_lang="<nllb_code>")
   ```
   so the model must accept `src_lang` / `tgt_lang` keyword arguments.

2. **Uses NLLB-style language codes** — target languages are specified as
   4-letter script-tagged BCP-47 codes (e.g. `"deu_Latn"`, `"zho_Hans"`,
   `"arb_Arab"`). Models that use different tag formats (e.g. mBART-50's
   `"de_DE"`) are not directly compatible without a wrapper.

The simplest compatible model is `facebook/nllb-200-distilled-600M`. Any
model fine-tuned on top of NLLB-200 that preserves the HuggingFace
`transformers.pipeline` interface will also work.
- `sacrebleu` — for BLEU and ChrF: `pip install sacrebleu`. spBLEU also needs
  `sentencepiece`, and the FLORES-200 tokenizer model is downloaded on first use;
  the entrypoint caches it before submitting to SLURM.
- `unbabel-comet` — for COMET: `pip install unbabel-comet`
- COMET model weights must be pre-downloaded on a login node before running
  on a compute node with `HF_HUB_OFFLINE=1`:
  ```python
  from comet import download_model
  download_model("Unbabel/wmt22-comet-da")
  ```

## Inputs

| Setting | Description | Default |
|---|---|---|
| `mqm.metrics` | Which metrics to compute (`"bleu"`, `"chrf"`, `"comet"`) | `["bleu", "chrf", "comet"]` |
| `mqm.languages` | Target language codes to evaluate | `["de", "zh", "es", "cs", "tr", "ha", "km"]` |
| `mqm.flores_split` | FLORES+ split to use as source/reference | `"devtest"` |
| `mqm.comet_model` | COMET model HuggingFace ID | `"Unbabel/wmt22-comet-da"` |
| `mqm.translation_batch_size` | Sentences per translation batch | `32` |
| `mqm.output_dir` | Directory to write `mqm_results.json` | `"./results/mqm"` |

Supported language codes: `de`, `zh`, `ru`, `he`, `es`, `cs`, `tr`, `uk`,
`ha`, `km`, `ps`, `sw`, `ht`, `lo`.

## Outputs

Results are written to `{output_dir}/mqm_results.json`:

```json
{
  "model": "facebook/nllb-200-distilled-600M",
  "languages_evaluated": ["de", "zh", "sw"],
  "flores_split": "devtest",
  "metrics_run": ["bleu", "chrf", "comet"],
  "metric_scores": {
    "de": {"bleu": ..., "chrf": ..., "comet": ...},
    ...
  },
  "metric_reliability": {
    "source": "AmanaMT v2 (Thompson and Ringger), revision of ACL Anthology 2026.wmt-main.42",
    "amana_mt_commit": "...",
    "statistic": "...",
    "languages": {
      "de": {
        "evidence": "direct_en_to_x",
        "label_type": "human_mqm",
        "language_pairs": ["en-de"],
        "directions": ["en_to_x"],
        "metrics": {
          "comet": {
            "pooled": {"spearman_r": ..., "spearman_ci": [..., ...], "pairwise_acc": ..., "n": ...},
            "en_to_x": {"spearman_r": ..., "n": ...}
          },
          ...
        }
      },
      "sw": {"evidence": "none", "label_type": "synthetic_mqm", "note": "...", ...}
    }
  },
  "recommendation": "..."
}
```

### Field descriptions

| Field | Description |
|---|---|
| `metric_scores` | Corpus-level averages of sentence-level scores. BLEU and chrF are 0–100; COMET is roughly 0–1. |
| `metric_reliability.languages.{lang}.evidence` | `direct_en_to_x`, `indirect` or `none` (see Evidence levels). |
| `...metrics.{metric}.pooled` | Spearman ρ (with bootstrap 95% CI over source sentences), pairwise accuracy and segment count over all of that language's labelled data in AmanaMT v2. |
| `...metrics.{metric}.en_to_x` | Spearman ρ on en->X data only; present only when such data exist. Prefer it when present. |
| `...note` | Caveat for the language (e.g. synthetic or uninformative labels). |
| `recommendation` | Plain-English summary limited to what the evidence supports. |
